# ABSTRACT

Household electricity consumption exhibits dynamic and non-stationary patterns driven by seasonal changes, weather variations, and evolving occupant routines. Traditional Machine Learning (ML) models trained on historical static datasets frequently suffer from concept drift, where predictive accuracy decays as underlying data distributions shift. This capstone project empirically investigates and compares strategies for maintaining predictive accuracy over time without incurring prohibitive computational costs. Using hourly smart-meter data from households in Bareilly, India, the study compares a Static Random Forest baseline against three online adaptation strategies: Periodic 7-Day Retraining, Sliding Window 7-Day Retraining, and ADWIN-triggered (Adaptive Windowing) retraining. To guarantee scientific integrity, a strict chronologically isolated walk-forward evaluation pipeline was engineered, mathematically precluding future-data leakage. The findings demonstrate that Periodic Retraining successfully mitigated model decay, yielding the highest accuracy (MAE = 0.087) compared to the Static baseline (MAE = 0.092). However, this required accumulating historical data, resulting in linearly increasing computational costs (9.04s retraining time). Conversely, the Sliding Window strategy bounded the computational payload, executing adaptations with near-zero latency (0.48s) while still offering competitive accuracy. These preliminary small-scale results underscore a fundamental accuracy-versus-cost trade-off in deploying predictive models for edge-level smart grid applications, establishing a robust, leak-free methodological framework ready for full-scale annual dataset evaluation.
